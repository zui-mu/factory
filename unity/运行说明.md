# 质因云联——从车间感知到生产决策的智慧工厂平台

这是 Unity 制作的交互式仿真工厂展示端，参考视频的园区布局与左右面板形式原创搭建。工厂名称位于左上角，中央展示园区，左右分别展示经营概况、当班人员与排班、联邦质量研判、零件质量与异常。

## 直接运行

已有 Windows 发布包时，双击本目录的 `启动仿真工厂.bat`，或打开 `Build/Windows/质因云联仿真工厂.exe`。从源码克隆后，请先在 Unity 中导出 Windows 程序。

Windows 10/11 64 位电脑无需安装 Unity、Python 或 MySQL 即可运行独立演示。推荐 1920×1080 屏幕；窗口可缩放。复制给别人时，必须把 **整个 Build/Windows 文件夹**一起复制，不能只复制 exe。

## 在 Unity 中编辑

使用 Unity Hub 打开本项目，版本为 **2022.3.62f3c1**（内置渲染管线）。打开 `Assets/FactoryTwin/Scenes/FactoryCampus.unity`，点击顶部 ▶ 播放。

所有园区建筑、设备、道路、树木与光伏都在场景层级中，可以直接修改位置、尺寸和材质。运行时生成仪表盘 UI。

当前场景参考用户提供的工业园视频搭建：白色金属厂房、浅色屋面上的分组光伏、屋顶采光与通风设施、蓝顶辅助厂房、通透围栏及物流道路；外围为细叶林带、山林地形及动态湖面。背景与中央视图同步旋转，左右面板采用半透明磨砂玻璃；原有模块、文字图表、主厂房排布与业务交互保持原样。辅助厂房与远景建筑只是视觉展示，不新增生产统计范围或设备控制。建筑与植被由原创代码生成，并非视频场景模型的直接复制。

菜单 **质因云联 → 导出 Windows 程序**可以重新生成运行程序。**生成或重建仿真园区**会覆盖生成场景与生成材质；手工调整场景前，建议另存场景。

## 操作与演示顺序

1. 点击厂房标签或数字 1–4，四个模块切换到对应产线与批次。
2. 左键拖动旋转，滚轮缩放，右键拖动平移。点击“自动漫游”启动或停止环绕观察。
3. 点击“进入车间”，剖开当前厂房的屋顶与外墙，观察设备往复运动和输送零件。点击设备可选择关联产线。“园区全景”恢复外观。
4. 点击“温控故障”，温度逐步升高；越限后设备停产。点击“安排检查”建立本地演示检查状态。
5. 点击“降温 / 复产”开始降温，稳定后再点击确认复产。复产后产生新的合格抽检记录，即可在质量详情中“确认复检通过”关闭本地演示任务。“暂停演示”同时暂停设备动画与累计数量增长。
6. “模型依据与适用范围”展示本厂与联合模型测试指标；“调整工艺编码试算”可计算不同条件的风险。试算不修改设备真实参数。
7. 查看排班、批次缺陷和可展开的工厂概况。Esc 关闭弹窗或回到园区。“退出”关闭独立程序。

## 与现有网页平台连接（可选）

独立演示不依赖网页平台。需要同步平台记录时，先通过仓库根目录的 `start.bat` 启动网页服务，再点击 Unity 右上角“连接平台”，填写地址和已有账号密码。默认地址为 `http://127.0.0.1:8765`；平台如果使用其他端口，请填写实际地址。

读取范围包括：设备传感参数、关联工单与批次、批次质检、已发布班表、已完成联邦训练结果。平台管理员可以切换工厂；其他账号只能访问自己有权限的工厂。平台操作员的班表遵循后台本人可见规则，模型试算也遵循后台角色权限。可点击“退出平台连接”注销会话，回到独立演示。Unity 与浏览器使用各自的登录会话，首次打开网页工作台时需要在浏览器中登录。

网页跳转使用连接时填写的服务器地址。三维展示端不直接连接 MySQL，也不向平台下发设备控制、排班或质检修改命令；这些操作通过现有网页完成。网络失联或采集过期时，显示通信未知并停止设备动画。

## 数据口径

- 三个演示工厂为星铸、云枢、曜光。当前共享一套园区展示几何，切换的是业务数据范围；每个车间的通用工作站模型共同展示该产线的主设备与批次状态。
- 当前经营卡片显示**估算产值**，计算为完成数量×演示参考单价；它不是营业额或回款。平台尚无销售收入接口时显示未配置。
- 人员是否当班依据排班时段，实际到岗需签到或现场确认。独立演示不读取真实考勤。
- 累计产量按节拍增加，故障、暂停、工单完成时停止。抽检记录以批次统计，不虚构单件追溯码。
- 内置模型由三个独立模拟样本集进行 10 轮 FedAvg 逻辑回归训练。训练、验证、测试集独立；部署依据验证集，界面指标来自测试集。没有假设联合模型一定优于本厂模型。
- 可运行 `python Tools/train_demo_model.py` 重现内置模型，无第三方 Python 依赖。模型推理使用实际权重，不是随机风险值。当前场景没有真实设备通信、测绘、差分隐私或安全聚合实现。
- 这是可编辑的仿真园区，不宣称是原工厂实测 1:1 重建。因果分析与 AI 建议通过已有网页工作台进入。

## 核心文件

| 文件夹 | 内容 |
| --- | --- |
| Assets/FactoryTwin/Scenes | 可编辑的正式场景 |
| Assets/FactoryTwin/Runtime | 交互、动态生产、UI、摄像机、模型推理、平台接口 |
| Assets/FactoryTwin/Editor | 场景生成与 Windows 导出 |
| Assets/FactoryTwin/Generated | 场景引用的材质资产 |
| Assets/FactoryTwin/Shaders | 地形与光伏屋面的材质着色器 |
| Assets/FactoryTwin/Resources | 模型权重、中文字体与字体许可证 |
| Tools | 模型生成脚本 |
| Build/Windows | 可直接运行的完整程序 |

提交 Unity 源码时保留 `Assets`、`Packages`、`ProjectSettings`、`Tools` 和本说明。`Library`、`Temp`、`Logs`、`obj` 是 Unity 本地缓存，无需提交；Unity 会重新生成。若同时提交运行程序，再附完整 `Build/Windows`。

中文字体使用 Noto Sans CJK SC，许可证为 SIL OFL 1.1，随字体保存。建筑和设备为本项目代码生成的原创几何。

# 质因云联——面向中小型制造业的质量诊断与跨厂区智能运维平台

## 统一运行说明

本文合并网页平台与 Unity 仿真工厂的运行方法，适用于本机演示、手机访问、其他电脑部署及源码交付。

- 网页平台版本：**1.5.0 · MySQL**。
- Unity 工程版本：**2022.3.62f3c1**，内置渲染管线。
- 整理日期：**2026年10月23日**。
- 网页项目位于仓库根目录。
- Unity 项目位于 `unity/`。

网页脚本和命令以仓库根目录为起点。Unity 的场景、脚本和构建路径以 `unity/` 为起点。

## 一、先选择运行方式

| 使用目的 | 启动方法 | 所需环境 |
| --- | --- | --- |
| 在电脑上使用网页平台 | 网页项目中的 `start.bat` | Python、MySQL；首次配置见下文 |
| 在手机上使用网页平台 | 电脑运行 `start-lan.bat`，手机访问电脑局域网地址 | 电脑与手机网络互通；手机只需浏览器 |
| 只展示三维仿真工厂 | Unity 项目中的 `启动仿真工厂.bat` | Windows 10/11 64位；独立程序无需安装Unity、Python或MySQL |
| 三维场景读取网页平台记录 | 先启动网页服务，再在Unity中选择“连接平台” | 可访问的网页服务，以及完整Unity运行程序 |
| 修改三维场景与脚本 | Unity Hub打开Unity项目 | Unity 2022.3.62f3c1；导出时需要Windows构建支持 |

**完整演示建议：先启动网页平台并登录，再启动Unity，按需要连接平台；手机演示时使用局域网启动方式。** `start.bat` 与 `start-lan.bat` 是同一网页服务的两种启动方式，无需同时运行。

网页前端资源和后端HTTP接口由同一Python服务提供，通常只需启动一次；不需要分别打开前端、后端命令窗口。Unity是单独的展示程序，可独立运行，也可通过HTTP接口读取平台数据。

## 二、在当前电脑启动网页平台

### 1. 启动与访问

1. 打开仓库根目录。首次使用请先完成第七节的 Python 和 MySQL 配置。
2. 双击 `start.bat`，等待启动窗口显示服务就绪。
3. 在电脑浏览器打开 **http://127.0.0.1:8765**；脚本通常会自动打开浏览器。
4. 演示期间保持启动窗口运行。不要直接双击 `frontend/index.html` 代替启动服务。

默认专用MySQL实例位于 `127.0.0.1:3307`，启动平台时会检查并自动启动数据库。已有 MySQL 服务使用 3306 时，项目实例仍可在 3307 独立管理数据。若已配置其他端口，以实际配置为准。

### 2. 登录账号与权限

首次初始化的演示账号密码均为 **`Zyyl@2026`**。已有账号如修改过密码，应使用修改后的密码；重新启动不会重置密码。

| 网页账号 | 身份与主要范围 |
| --- | --- |
| `admin` | 平台管理员，可切换星铸、云枢、曜光三个工厂并管理跨厂联邦任务 |
| `engineer` | 星铸工厂质量工程师，在本厂权限范围内诊断、派单与复核 |
| `operator` | 星铸工厂现场人员，处理授权任务，查看本人档案、排班与请假信息 |
| `manager` | 星铸工厂生产负责人，管理员工、班次、排班及请假审批 |
| `factory_b` | 云枢工厂质量工程师 |
| `factory_c` | 曜光工厂质量工程师 |

网页登录账号与MySQL连接账号是两套账号。普通用户不因使用手机或Unity而获得跨厂权限。网页中的“退出登录”用于注销当前浏览器会话，不会自动停止后台生产演示或关闭服务器。

## 三、手机访问网页平台

1. 让手机和运行平台的电脑连接同一Wi-Fi、同一路由器或可互通的热点网络。
2. 如果已用 `start.bat` 启动8765端口服务，先在原启动窗口按 `Ctrl+C` 停止网页服务。
3. 在网页项目根目录双击 `start-lan.bat`，使网页服务允许局域网访问。
4. 在电脑上运行 `ipconfig`，查找实际联网网卡的IPv4地址；也可使用启动窗口显示的可访问地址。
5. 在手机浏览器输入 `http://电脑当前IPv4地址:8765`。例如电脑地址为 `192.168.5.175` 时，输入 `http://192.168.5.175:8765`。

示例IP不是固定地址，换Wi-Fi或热点后需要重新确认。手机不能用 `127.0.0.1` 或 `localhost` 访问电脑，这两个地址在手机上指向手机自身；`0.0.0.0` 是服务监听设置，也不是手机应输入的网址。

遇到Windows防火墙提示时，允许Python在自己的可信网络通信。手机访问的是网页服务端口8765，**不需要对局域网开放MySQL的3307端口**。若平台实际使用其他网页端口，手机与Unity均应填写实际端口。

## 四、启动与操作Unity仿真工厂

### 1. 直接运行

已有 Windows 发布包时，在 `unity/` 中双击以下脚本。从源码克隆后，需要先按第八节导出 Windows 程序。

```text
启动仿真工厂.bat
```

也可以直接运行：

```text
Build\Windows\质因云联仿真工厂.exe
```

Windows 10/11 64位电脑可以直接运行已导出的独立程序。推荐1920×1080屏幕，窗口可缩放。**复制给别人时必须复制整个 `Build\Windows` 文件夹**，其中包括程序、`质因云联仿真工厂_Data`、`UnityPlayer.dll`、`MonoBleedingEdge` 及随附文件，不能只复制exe。

如果只收到 `Build\Windows` 内的文件，直接双击其中的exe即可，无需Unity工程根目录中的启动脚本。

左上角显示工厂名称，中央展示园区，左右四类面板分别为经营概况、当班人员与排班、联邦质量研判、零件质量与异常。

| 操作 | 作用 |

| 点击车间设备 | 选择关联产线 |

### 3. 独立演示流程

独立演示不依赖网页服务，以下操作使用本地演示数据和检查状态：

1. 选择厂房，查看对应产线、批次、排班和质量信息。
2. 点击“进入车间”，观察设备与零件运动。
3. 点击“温控故障”，温度逐步升高，越限后设备停产。
4. 点击“安排检查”，建立本地演示检查状态。
5. 点击“降温 / 复产”开始降温；稳定后再次点击确认复产。
6. 复产后产生新的合格抽检记录，再在质量详情中选择“确认复检通过”，关闭本地演示任务。
7. 点击“模型依据与适用范围”查看本厂和联合模型指标；“调整工艺编码试算”使用模型权重计算风险，不改变真实设备参数。

“暂停演示”同时暂停设备动画和累计数量增长。还可查看排班、批次缺陷和展开的工厂概况。连接平台后的操作范围见下一节，本地演示按钮不代表可以远程控制真实设备。

## 五、Unity连接网页平台

### 1. 连接步骤

1. 启动网页平台，确认电脑浏览器能够正常访问并登录。
2. 打开Unity运行程序，点击右上角“连接平台”。
3. 填写服务器地址和现有网页账号密码。
4. 网页平台与Unity在同一电脑时，默认地址为 `http://127.0.0.1:8765`。
5. 如果Unity运行在另一台电脑上，服务器应通过 `start-lan.bat` 启动；在Unity中填写服务器电脑当前的局域网IP和端口。

### 2. 读取内容与操作边界

Unity可读取平台的设备传感参数、关联工单与批次、批次质检、已发布班表和已完成联邦训练结果。管理员可以切换工厂，其他账号只能访问已授权范围；操作员班表可见性和模型试算权限遵循后台规则。

三维展示端通过平台HTTP接口访问数据，**不直接连接MySQL**。它不向平台下发设备控制、排班或质检修改命令；需要修改业务记录时，进入网页工作台完成操作。网络失联或采集过期时，显示通信未知并停止设备动画。

“网页工作台”使用连接时填写的服务器地址。Unity与浏览器使用各自的登录会话，首次打开网页工作台时可能需要在浏览器中重新登录。

点击“退出平台连接”可注销Unity会话并返回独立演示。它与网页“退出登录”、Unity“退出程序”、后台“停止服务”是不同操作。

## 六、网页平台推荐体验流程

### 1. 生产、诊断与处置

1. 登录后查看生产监控、设备、工单和批次信息。
2. 在生产监控页点击“启动演示产线”，预热后观察报工、耗料与检测变化。
3. 可触发短停、换料或温控故障，温控恢复稳定后点击“确认复产”。
4. 查看质量异常和因果诊断证据，使用因果问答助手了解排查依据及适用范围。
5. 由有权限的人员创建处置任务，现场人员接单、处理并提交，授权人员复核后关闭或退回。
6. 以管理员身份进入联邦分析，启动联合训练并查看节点、轮次及模型结果。

因果问答默认使用**本地证据助手**；可选外部模型的配置方法见网页项目中的 `backend/AI_CONFIG.md`。没有配置外部模型时，本地流程仍可运行。三路监控视频是录制素材，动态工况和算法样本为模拟数据，当前未连接真实工厂设备。

### 2. 人员、排班与派单

登录后打开“人员与排班”：

1. 使用 `admin` 或 `manager` 维护员工工号、岗位、班组、技能和绑定账号。
2. 设置班次起止时间，发布排班时选择日期、产线、技能、所需人数与人员。
3. 提交和审批请假后，查看班表缺员人数；在“调整 / 替班”中更换人员并填写说明。
4. 从因果诊断或异常检查进入派单，优先选择当班、技能匹配、同产线且待办较少的人员。

非当班或技能待核验时需要调度说明，正在批准请假期间或停用的人员不可派单；调度依据保存于工单时间线。质量工程师可以查看本厂班表及技能信息，现场人员只查看本人档案、班表和请假信息；详细请假原因仅本人和管理人员可见。

跨日班次按开始日期归属。重叠排班、批准请假冲突和技能不符合会阻止保存；相邻班次休息不足11小时会提醒负责人核对，这是平台提示阈值。人数不足可先发布并显示缺员；请假与班次部分重叠时按整班不可用提示补员。取消、调整和多人修改均有审计或版本检查。

已发布班表保留原班次时间，修改班次模板只影响后续新增排班。系统按北京时间运行，电脑和手机应使用UTC+8时区。“当班”来自排班时间和批准请假计算，**不等于考勤或实际到岗**。

初始化时，每厂生成6个演示员工、早晚两个班次及起始7天内工作日的模拟班表，演示工号以 `DEMO-` 开头。初始班表不会随日期自动续排，之后由负责人维护。未绑定账号的员工可参与排班，但接收平台工单需要绑定本厂已有登录账号。

## 七、在其他电脑首次部署

### 1. 网页平台

1. 安装 **Python 3.9或以上版本**并加入PATH，安装 **MySQL Server 8.0.16或以上版本**。
2. 将仓库放在有写入权限的目录。首次配置会在仓库根目录生成 `.venv` 和 `data`。
3. 在新电脑双击 `setup.bat`。脚本建立Python虚拟环境、安装PyMySQL，并利用已安装的MySQL程序在项目 `data` 目录中初始化专用实例、四个库和专用账号。默认使用3307端口，不需要原电脑MySQL服务密码。
4. 配置完成后运行 `start.bat`；需要手机或其他电脑访问时使用 `start-lan.bat`。
5. 首次启动会创建模拟业务数据与节点训练样本。新部署默认不会继承原电脑的历史工单、照片和训练记录；如需保留，按备份与恢复流程处理。

首次安装Python依赖需要网络；配置完成后，本地平台、因果分析和联邦训练可离线使用。网页平台无需安装Node.js、Java或Unity。

MySQL安装位置特殊时，可先在PowerShell中指定程序路径，再运行首次配置：

```powershell
$env:ZY_MYSQLD = '实际MySQL安装目录\bin\mysqld.exe'
.\setup.bat
```

默认3307已被其他服务占用时，首次配置可改用：

```powershell
.\setup.bat --mysql-port 3308
```

这修改的是MySQL端口，网页默认地址仍使用8765。

### 2. 使用自行管理的MySQL（可选）

这是默认项目专用实例之外的可选配置方式，常规演示无需执行。准备好虚拟环境及PyMySQL后，在首次配置时运行：

```powershell
.\.venv\Scripts\python.exe -X utf8 -B backend/tools/setup_mysql.py
```

按提示输入数据库管理连接信息。工具只创建新数据库和专用账号，拒绝覆盖同名库。已有业务库配置格式参考 `backend/config.example.json`；数据库和表结构需要事先建立。

常规启动读取 `data/mysql.json`；也支持 `ZY_MYSQL_HOST`、`ZY_MYSQL_PORT`、`ZY_MYSQL_USER`、`ZY_MYSQL_PASSWORD`、`ZY_MYSQL_DATABASE` 等环境变量。不要把网页登录账号填作数据库管理账号。

### 3. Unity独立程序

复制完整 `Build\Windows`，在目标Windows 10/11 64位电脑上运行 `质因云联仿真工厂.exe`。仅展示独立场景无需安装Python、MySQL或Unity；连接平台时使用可访问的服务器地址。

## 八、Unity工程编辑与重新导出

1. 在Unity Hub中添加Unity项目目录，使用 **2022.3.62f3c1** 打开。
2. 打开场景 `Assets/FactoryTwin/Scenes/FactoryCampus.unity`。
3. 点击编辑器顶部播放按钮运行；需要结束预览时再次点击播放按钮。
4. 通过菜单“质因云联 → 导出 Windows 程序”重新生成 `Build/Windows` 中的运行程序。

园区建筑、设备、道路、树木与光伏位于场景层级中，可调整位置、尺寸及材质；仪表盘UI在运行时生成。当前风格包括金属厂房、光伏屋面、屋顶采光与通风设施、蓝顶辅助厂房、围栏与物流道路，以及树林、远山和动态湖面。辅助厂房及远景建筑用于视觉展示，不增加生产统计范围。

**“生成或重建仿真园区”会覆盖生成场景和生成材质。** 手工编辑前先另存场景，避免调整被重建操作覆盖。

如需重现内置演示模型，在Unity项目根目录执行：

```powershell
python Tools/train_demo_model.py
```

该脚本无需第三方Python依赖；只运行已导出的Unity程序时不需要执行此步骤。模型资源发生变化后，如需在独立程序中体现，应重新导出Windows程序。

## 十、数据库、测试与备份

### 1. 数据库位置与账号隔离

| 项目 | 默认位置或名称 |
| --- | --- |
| 主业务库 | `zhiyinyunlian` |
| 三厂节点库 | `zhiyinyunlian_factory_1`、`zhiyinyunlian_factory_2`、`zhiyinyunlian_factory_3` |
| 应用连接配置 | `data/mysql.json` |
| 本机实例管理配置 | `data/mysql-local/admin.json` |
| MySQL实际数据目录 | `data/mysql-local/db/`，由MySQL管理 |
| 排班建表脚本 | `backend/sql/workforce.sql` |
| 历史数据的 SQL 备份 | `data/backups/`，内容以导出时间为准 |

MySQL使用InnoDB、utf8mb4、外键和事务。三个训练节点使用独立数据库与账号，节点账号不能访问其他厂的样本，主业务账号不能直接读取节点样本；联合训练通过三个本地进程的HTTP接口交换参数。

常规首次部署使用 `setup.bat` 和启动脚本即可，无需额外手动导入完整SQL。不要直接编辑MySQL数据文件，也不要把含密码的 `data` 配置作为比赛源码提交。

### 2. 运行测试

在网页项目中双击：

```text
backend\run-tests.bat
```

测试创建独立的 `zyyl_test_随机编号` 数据库，结束后清理测试资源，不使用平台业务库。自行管理MySQL时，应先设置 `ZY_MYSQL_TEST_CONFIG`，指向可创建测试库的管理连接JSON文件。

测试脚本如提示找不到样本文件，核对附带CSV与脚本引用的实际文件名；应修正输入路径后再完整执行，不能把加载失败算作通过。

### 3. SQL备份与恢复

暂停生产演示、联合训练和业务写入后，在网页项目根目录执行：

```powershell
.\.venv\Scripts\python.exe -X utf8 -B backend/tools/backup.py
```

备份输出为 `data/backups/zyyl-mysql-时间.zip`，包含主库与三节点库的标准SQL、上传照片及SHA-256校验文件。

恢复时将四份SQL分别导入对应空库，恢复上传照片到 `data/uploads`，并配置匹配的账号和数据库连接。源码与业务备份分开保管，向他人提供业务数据前检查其中的敏感内容。不要直接复制正在运行的MySQL数据目录代替备份。

### 4. 历史SQLite迁移（可选）

仅在确有旧SQLite数据时使用 `backend/tools/migrate_sqlite.py`；目标必须为空库。工具保留原编号、密码、业务记录和训练模型，并逐行核对。当前平台运行使用MySQL，SQLite只作为迁移来源，日常启动无需执行迁移。

## 十一、退出与停止服务

| 操作 | 影响 |
| --- | --- |
| 网页“退出登录” | 注销该浏览器会话；不停止后台演示、网页服务或MySQL |
| Unity“退出平台连接” | 注销Unity的平台会话并返回独立演示 |
| Unity“退出” | 关闭三维运行程序；网页服务独立运行 |
| 网页启动窗口按 `Ctrl+C` | 停止网页服务；MySQL实例继续后台运行 |
| 执行下方停库命令 | 停止项目专用MySQL实例；应先停止网页平台 |

需要停止MySQL时，先停止网页服务，再在网页项目根目录执行：

```powershell
.\.venv\Scripts\python.exe -X utf8 -B -m backend.local_mysql --stop
```

下次运行启动脚本会自动启动项目专用MySQL。不要在MySQL运行时移动项目目录或删除 `data/mysql-local`。

## 十二、常见问题

| 现象 | 排查方法 |
| --- | --- |
| 电脑打不开网页 | 确认启动窗口仍运行，先访问 `http://127.0.0.1:8765`，查看Python、MySQL及端口错误；不要直接打开HTML文件 |
| 手机提示服务器无响应或很慢 | 先确认电脑可访问；检查是否用局域网脚本启动、手机与电脑是否互通、IP是否已变化，以及防火墙与热点/路由器是否限制设备互访 |
| 切换到局域网启动后仍不可访问 | 先停止原本仅监听本机的服务，再用 `start-lan.bat` 启动；重复启动同端口不会自动改变原服务的监听方式 |
| 登录失败 | 区分网页账号与数据库账号，检查大小写和是否改过密码；首次演示密码为 `Zyyl@2026` |
| 普通账号只能看一个工厂 | 属于角色与工厂范围控制；需要跨厂演示时使用管理员账号 |
| 排班页面没有当前日期记录 | 初始模拟班表不会自动续排，由管理员或生产负责人发布当前日期的班次 |
| Unity提示找不到程序或DLL | 确认复制了完整 `Build/Windows`，而非仅exe；尚未导出时先在Unity编辑器中构建 |
| Unity无法连接平台 | 先用浏览器验证同一服务器地址；跨电脑时使用服务器IP，检查网页服务、账号权限与端口 |
| Unity进入网页后又要登录 | Unity与浏览器使用独立会话，这是正常行为 |
| Unity显示通信未知或动画停止 | 检查平台连接及设备数据是否过期，避免将陈旧数据当作实时状态 |
| 默认MySQL端口被占用 | 新部署时用 `setup.bat --mysql-port 3308` 等未占用端口；已有部署先核对配置和占用情况 |

## 十三、数据口径、适用范围与素材说明

- 星铸、云枢、曜光是匿名演示工厂。Unity当前共享一套园区几何，切换的是业务数据范围；通用工作站用于展示各产线主设备与批次状态，不代表三座真实厂区的测绘模型。
- Unity独立模式采用演示数据；连接平台后按授权范围读取平台记录。平台当前包含模拟工况、模拟算法样本与监控视频素材，未连接真实工厂设备。
- 经营卡片的“估算产值”为完成数量乘以演示参考单价，不是营业额或回款；平台未配置销售收入接口时显示未配置。
- 人员“当班”依据班表时段及请假信息计算，实际到岗需签到或现场确认。
- 独立演示产量按节拍增加，故障、暂停或工单完成时停止；抽检按批次统计，不虚构单件追溯码。
- 内置模型使用三个独立模拟样本集进行10轮FedAvg逻辑回归训练，训练、验证、测试集独立；模型是否启用依据验证集，展示的效果指标来自测试集，不假设联合模型一定优于本厂模型。风险试算使用实际权重计算，不是随机风险数值。
- 当前未实现真实设备控制通信、实测1:1建模、差分隐私或安全聚合。因果诊断与AI建议通过网页工作台使用，结果需结合数据来源、模型假设和现场工艺判断。
- 园区建筑与设备几何由项目代码生成，参考视频用于风格和布局参考，不直接复制参考视频中的场景模型。涉及AI辅助生成及外部素材时，按实际制作记录说明来源和使用范围。
- 中文字体使用Noto Sans CJK SC，许可证为SIL OFL 1.1；保留项目资源及运行包中的字体许可证。网页素材与代码来源说明见 `backend/SOURCES.md`。
